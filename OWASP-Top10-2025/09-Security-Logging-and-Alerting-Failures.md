# A09:2025 - Security Logging and Alerting Failures

## What is it?
Insufficient logging, monitoring, and alerting allows attacks to go undetected.

## Example:
Attacker tries 1000 wrong passwords but no alert is triggered

## Prevention:
- Log all authentication and access control events
- Set up real-time alerts for suspicious activity
- Centralize logs and monitor them
- Test alerting regularly
